# FOODSAFE V2

Protótipo conceitual/ acadêmico desenvolvido em React + Vite + Tailwind CSS.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite.

## Publicar

Este projeto pode ser enviado para Vercel, Netlify ou outro serviço compatível com Vite.

Build de produção:

```bash
npm run build
```

Os dados, pesquisas, planos e funcionalidades apresentados no site são simulados para demonstração acadêmica.
